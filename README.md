# Dr. A. T. Ahamed Mohideen — Professional Medical & Research Profile Website

Official static corporate website for **Dr. A. T. Ahamed Mohideen**, B.H.M.S., M.D. (Hom.) in Paediatrics — Clinician, Medical Researcher, and Senior Project Associate at SRMIST.

## Stack & Architecture
- **Framework:** Vite 5.4 (Static Site Output)
- **Languages:** HTML5, CSS3 (Custom CSS Tokens), Vanilla JavaScript
- **Deployment:** Vercel / Netlify / Any Static Web Host

## Project Structure
```
DR-ATM/
├── index.html            # Home Overview Page
├── about.html            # Profile, Philosophy & Career Journey
├── practice.html         # Clinical Practice & Paediatric Care
├── research.html         # Research Projects & Academic Dissertations
├── achievements.html     # Academic Ranks, Awards & Publications
├── contact.html          # Contact & Consultation Form
│
├── src/
│   ├── css/
│   │   └── style.css     # Corporate Medical Design System
│   └── js/
│       └── main.js       # Sticky Header, Active Links & WhatsApp Form Logic
│
├── package.json
└── vite.config.js
```

## Local Development & Build
1. `npm install`
2. `npm run dev` (Local Dev Server)
3. `npm run build` (Generate production dist/)
4. `npm run preview` (Preview static build output)
